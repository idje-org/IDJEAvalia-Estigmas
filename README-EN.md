# ESTIGMA — Public Audit Package

Independent verification package for the ESTIGMA benchmark results
(7 models × 7,928 prompts in Brazilian Portuguese), including the
pt-BR ↔ EN contrastive sub-analysis (language effect).

**This is not a reproducibility package** (no API keys, no evaluation scripts,
no original English dataset). It contains all data and scripts needed for an
independent auditor to **verify the published numbers** in `MATERIAL_DIVULGACAO.md`
and `ACHADOS_IDIOMA.md`.

## Auditing the main study

### 1. Per-model metrics

```bash
cd auditoria_publica
python3 scripts/scorer.py resultados/modelo_1.csv
```

Replace `modelo_1.csv` with any `modelo_N.csv`. Output includes:
- Overall bias, "don't know" by style, positive accuracy
- Per-danger segmentation (χ²), gender, racial/xenophobia axes
- Top biased stigmas

Compare against `saida/modelo_N.txt`.

### 2. Paired model comparison (McNemar)

```bash
python3 scripts/scorer.py resultados/modelo_*.csv
```

Output includes a p-value matrix (McNemar) comparing decisive responses
(`sim`/`não`) versus abstention for every model pair on the same prompts.
Compare against `saida/comparativo_mcnemar.txt`.

Install the pinned dependency with:

```bash
python3 -m pip install -r requirements.txt
```

`scipy` is required for χ² and McNemar.

## Auditing the pt-BR ↔ EN language analysis

```bash
cd auditoria_publica/idioma
python3 scripts/audit_lang_effect.py
```

The script reads the samples (`amostras/`) and paired results (`resultados/`)
and produces the consolidated table, McNemar tests, and cross-model pattern.

**Requires:** `scipy` (for McNemar). **No API required.**

Alternatively, run the top-level script (re-performs nth-occurrence pairing
from the full dataset):

```bash
cd auditoria_publica
python3 scripts/audit_lang_effect.py
```

shasum -a 256 -c CHECKSUMS.sha256

## Known limitations

1. **Nth-occurrence pairing:** the async `evaluate.py` does not preserve prompt
   order. Pairing uses textual prompt lookup with a consumption counter.
2. **`inconclusivo` (unparseable) handling:** unparseable answers are treated as
   abstention (`não sei`), consistent with the original `scorer.py`.
3. **Gender segmentation in the language analysis:** 76% of EN prompts use
   they/them (gender-neutral); pt-BR-detected gender is applied to both languages.
